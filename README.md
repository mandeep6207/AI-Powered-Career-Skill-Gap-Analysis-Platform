# SkillGap Navigator

Full-stack SaaS-style demo: React + Vite frontend and Flask backend with SQLite.

Run frontend:

```bash
cd frontend
npm install
npm run dev
```

Run backend:

```bash
cd backend
python -m pip install -r requirements.txt
python app.py
```

API endpoints:
- POST /signup
- POST /login
- POST /analyze
- GET /history
- GET /profile

This repo scaffolds a minimal working example for local development.
